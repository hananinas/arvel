## Unresolved distribution and public-demonstration blockers

1. **Restricted Espressif components in the linked firmware.** `components/audio_bsp/CMakeLists.txt` requires `codec_board` and `espressif__esp_codec_dev`; `components/speech_tts/CMakeLists.txt` requires `espressif__esp_peer` and `espressif__esp_audio_codec` alongside the linked GPL speech engine. The following are **Espressif Modified MIT**, not ordinary MIT:
   - `components/codec_board/LICENSE`
   - `managed_components/espressif__esp_audio_codec/LICENSE`
   - `managed_components/espressif__esp_peer/LICENSE`

   Each retains Copyright (c) 2025 Espressif Systems (Shanghai) CO., LTD, grants use exclusively with Espressif products, requires retention of the copyright/permission notice, and prohibits source or binary redistribution for use with non-Espressif products. These additional product-use restrictions present an unresolved compatibility obstacle to distributing a combined GPL/AGPL firmware. Using an ESP32 does not itself resolve the copyleft recipient-rights conflict. Before distributing combined binaries or claiming the complete work is unrestricted open source, obtain appropriate permissions/exceptions from the relevant rights holders or remove/replace the incompatible components and establish the resulting license compatibility. This notice and a root original-code license are not such permissions.

2. **NVIDIA serving container and public access/results.** The released checkpoint `nvidia/NVIDIA-NemotronLabs-VoiceChat-11B` model card declares **OpenMDW-1.1**. That declaration does not license the separately supplied NGC realtime evaluation container targeted by `scripts/VOICECHAT_DEPLOYMENT.md` and `scripts/voicechat_deploy.py`. The **NVIDIA Software and Model Evaluation License**, last modified February 26, 2025, restricts the licensed materials to internal testing/evaluation on NVIDIA GPUs, not production (§1.1); restricts access to authorized internal users (§3); requires prior written consent for disclosure of evaluation/test results (§2.13); and requires prior written approval for publicity or public information/results (§11). The agreement also limits distribution (§2.2), imposes confidentiality (§10), and has a six-month initial-download term (§13.1).

   Public hackathon demonstration, public video/results and unrestricted judging access are **not established as permitted**. Required prerequisites are the governing terms for the actual immutable image/model artifacts, a valid evaluation term and authorization for the intended users, and NVIDIA's written permission covering intended public demonstration, disclosure/publicity and judging access (or a separately authorized serving implementation whose actual licenses permit those activities). An operator acknowledgment, checkpoint conversion, model license or GPU-provider account is not a substitute. No NVIDIA model weights or container are redistributed by this notice.

   Sources: [released model card](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B), [OpenMDW-1.1](https://github.com/OpenMDW/OpenMDW/blob/main/1.1/LICENSE.OpenMDW-1.1), [NVIDIA evaluation agreement](https://www.nvidia.com/en-us/agreements/enterprise-software/nvidia-software-and-model-evaluation-license/). The separately described early-access Nemotron 3 VoiceChat 12B is not the released Labs 11B artifact and is not covered by this model-card license declaration.

3. **Arvel Buddy artwork, design bundle and branding.** `Arvel Buddy — ESP32 Display.html` is the source bundle consumed by `scripts/generate_arvel_assets.py` for scenes, character, icons and generated `components/ui_bsp/arvel_art.c`; the interface also contains Arvel-named visual components. No applicable artwork/design/branding redistribution grant was identified in the inspected material. Font permission is not permission for the surrounding design, character, scenes, logos, name or marks. Rights remain **unverified**, not presumed public domain or relicensed by code generation. Before publishing/distributing these assets or using the branding publicly, establish the creator/rights-holder provenance and retain a grant covering modification, source/binary redistribution and the intended public/trademark use, or replace them with assets/branding for which those rights are established. This review does not claim an exhaustive legal search of every encoded bundle asset.

## Fonts: actual file provenance and retained full licenses

The Arvel native fonts are compiled from `components/ui_bsp/fonts/*.c` by `components/ui_bsp/CMakeLists.txt`. `scripts/generate_arvel_assets.py` documents and implements variable-weight instancing, glyph subsetting, LVGL bitmap conversion and synthetic italic shearing. These are **modified/converted font versions**, not original upstream font releases; native names such as `arvel_font_*` and `arvel_mono_*` identify those generated versions. Font software, including converted glyph data, retains **SIL OFL 1.1**, not a blanket Arvel software license. Keep its copyright and full license with both source and binary/font distributions; do not sell font software by itself or imply author endorsement. Any reserved-font-name rules remain applicable.
